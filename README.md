# Bubble Bobble Clone

## Controls

The game uses Godot's InputMap actions:
- `ui_left`: Move left
- `ui_right`: Move right
- `ui_up`: Jump
- `ui_down`: Drop down
- `ui_accept`: Start game / interact
- `ui_cancel`: Pause / back
- `shoot`: Blow bubble

- No multiplayer support

## How to Run

1. Open the project in Godot Engine (version 3.x or 4.x).
2. Run the main scene: `scenes/main/Main.tscn`.
3. Use the controls above to play.
